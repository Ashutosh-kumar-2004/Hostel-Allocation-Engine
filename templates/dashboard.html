Modular Architecture Navigation

Each functional module is an isolated Django app with its own models and exposed service layer.

M1 · Inventory Hostel → Bed
Hostels, Blocks, Floors, Rooms (AC/Cooler), variable bed capacities.
M2 · Applications Cycle Windows
Application intake, student profiles, academic programmes, accessible flags.
M3 · Eligibility Rules Engine
Distance, CGPA, disciplinary record rules with transparent pass/fail reasons.
M4 · Preferences Ranked Choices
Ranked hostel preferences, room types (Single/Double/Dorm), roommate requests.
M5 · Compatibility Consented ML/Data
Lifestyle questionnaire (sleep, study, hygiene) pairwise matching scores.
M6 · Allocation Pure Python
Constraint heuristic engine: Bed capacity, gender, accessibility, seed tiebreaks.
M7 · Warden Review Approval Gate
Draft bed review, manual reallocation with mandatory reasons, warden sign-off.
M8 · Waitlist Auto-Promotion
Ordered priority queue with automatic offer dispatch upon bed cancellations.
M9 · Publication WeasyPrint PDF
Gated by approval; immutable publication record; automated PDF letter generation.
